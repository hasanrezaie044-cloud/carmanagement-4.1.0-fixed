# Custom changes 4.0.1

- All default monetary service/fuel/toll rates and time-bonus percentages are now 0 so the owner enters current rates.
- Service Hours are manual for every service. Start/end times no longer overwrite Hours; they remain available for time-bonus logic.
- Added first-use Persian service-entry tutorial. It appears when the user first opens the Service tab and is then permanently marked as seen.
- Completed loans are automatically removed after the final installment is paid. Overdue installments are checked when the loan section opens, and legacy already-completed loans are cleaned up.
- Dashboard sections Comparison & Trend, Annual Statistics, Personnel, and Recent Services are collapsed by default and expand as a compact bar.
- Settings sections are collapsed by default and expand as compact bars. Each header includes an English subtitle.
